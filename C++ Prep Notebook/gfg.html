Q1. What is C++? Done

C++ ek general-purpose, compiled, multi-paradigm programming language hai jo Bjarne Stroustrup ne C ke extension ke roop mein banayi (pehle naam "C with Classes" tha). Ye procedural, object-oriented aur generic programming (templates) teeno support karti hai, isliye system-level aur application-level dono kaam ke liye use hoti hai.

Origin: 1979, Bell Labs. C fast tha par bade programs organize karna mushkil; Simula mein classes thi par slow thi. Idea: "C ki speed + Simula ki organization." 1983 mein naam C++ pada (++ = C ka next version).

Advantages: yaad rakho POP-MS

  • P — Performance: Seedha machine code mein compile hoti hai, koi VM nahi. Hardware ke paas hai, isliye fast.
  • O — Object-Oriented: Encapsulation, inheritance, polymorphism, abstraction, toh code modular aur reusable.
  • P — Portability: Same source code alag platforms pe chal jaata hai, bas har platform ke liye recompile.
  • M — Memory Control: Pointers, new/delete, stack vs heap tumhare haath mein. Garbage collector nahi, cleanup RAII se, timing predictable.
  • S — STL: Ready-made containers (vector, map), algorithms (sort, find), iterators.

Depth line: C++ zero-overhead principle follow karti hai: jo feature use nahi karte, uski keemat nahi dete. (Har word ka matlab: Foundations.)

Standards: C++98 → 03 → 11 (sabse bada jump: auto, lambdas, smart pointers, move semantics, <thread>) → 14 → 17 → 20 → 23. Har 3 saal mein naya.

Kahan use hoti hai: OS components, game engines (Unreal), browsers (Chrome), databases (MySQL), compilers, embedded, high-frequency trading, simulation tools.

Interview mein (30 sec)

"C++ ek compiled, multi-paradigm language hai jo C ke upar bani hai. Isme C jaisi speed aur low-level memory control milta hai, saath mein OOP aur templates jaisi high-level abstractions bhi. Iska core idea zero-overhead abstraction hai. Isliye performance-critical software, jaise engines, databases, browsers, simulation tools, mein use hoti hai. Isliye mujhe lagta hai MathWorks jaise products ke liye ye natural fit hai."

Interviewer poochegaJawab
"Purely OOP hai?"Nahi. main() aur global functions class ke bahar hote hain, int jaise primitive types objects nahi hain. "Multi-paradigm" bolo.
"Java jaisi portable hai?"Source portable hai, binary nahi. Java bytecode ek baar compile hoke JVM pe kahin bhi chalta hai.
"Garbage collection kyun nahi?"Performance aur predictability. RAII + smart pointers se cleanup deterministic hota hai.
